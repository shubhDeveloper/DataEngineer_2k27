======================================================================
                 DATA ENGINEER LEARNING ROADMAP
              COMPLETE TECHNOLOGY CHECKLIST + TIMELINE
======================================================================

TARGET
------
Prepare for Data Engineer / Senior Data Engineer roles through programming,
database engineering, data architecture, big data, cloud, orchestration,
streaming, engineering practices and system design.

DURATION: 9 MONTHS
STUDY TIME: 12-15 HOURS PER WEEK
PRIMARY CLOUD: MICROSOFT AZURE
SECONDARY CLOUD: AWS

Use this as a suggested sequence. Learn the fundamentals, practise them,
build the milestone project, and then move to the next phase.
