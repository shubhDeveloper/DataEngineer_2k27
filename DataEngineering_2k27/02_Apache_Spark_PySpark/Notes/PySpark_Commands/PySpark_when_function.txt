### Detailed Explanation of `when`

1. **Purpose**:
   - The `when` function (`pyspark.sql.functions.when`) allows conditional logic in PySpark DataFrames, similar to `if-else` in Python or `CASE WHEN` in SQL.
   - It evaluates a condition and returns a value if true, with chaining for multiple conditions and an `otherwise` clause for defaults.
   - Common uses:
     - Create new columns based on conditions (e.g., salary categories).
     - Transform existing columns (e.g., conditional bonuses).
     - Handle nulls or default values.

2. **Syntax**:
   ```python
   from pyspark.sql.functions import when, col
   df.withColumn("new_column", when(condition, value).when(condition, value).otherwise(default))
   ```
   - `condition`: A boolean expression using `col()` (e.g., `col("Annual Salary") > 10000`).
   - `value`: The value to return if the condition is true (can be a literal, column, or expression).
   - `otherwise(default)`: The value to return if no conditions are met (optional, defaults to `null`).
   - Returns a `Column` object, so it must be used with `withColumn()` or `select()`.

3. **Key Features**:
   - **Chaining**: Multiple `when` clauses can be chained to handle different conditions (evaluated in order).
   - **Logical Operators**: Use `&` (AND), `|` (OR), and `~` (NOT) for complex conditions, with parentheses to avoid precedence issues (e.g., `(col("A") > 10) & (col("B") < 20)`).
   - **Null Handling**: Use `isNull()` or `isNotNull()` to handle null values.
   - **Lazy Evaluation**: The `when` operation is planned but executed only with actions (e.g., `display()`, `show()`).
   - **SQL Equivalent**: `CASE WHEN` in `spark.sql()` or `%sql` achieves the same logic.

4. **Use Cases with `df_new`**:
   - **Categorization**: Classify `Annual Salary` into ranges (e.g., Low: <20,000, Medium: <50,000, High: >=50,000).
   - **Conditional Computations**: Assign bonuses based on `department` and `Annual Salary`.
   - **Null Handling**: Replace null `Annual Salary` values with a default (e.g., `0.0`).
   - **Flagging**: Create a flag column (e.g., `is_mid_range` for salaries between 10,000 and 20,000).

5. **Relation to Your Previous Filter**:
   - Your previous error with `df_new.filter(col("Annual Salary") > 10000 & col("Annual Salary") < 20000)` involved filtering rows. The `when` function complements this by allowing you to create a new column based on similar conditions rather than filtering rows.
   - Example: Instead of filtering salaries between 10,000 and 20,000, you could use `when` to flag them:
     ```python
     df_new.withColumn("is_mid_range", when((col("Annual Salary") > 10000) & (col("Annual Salary") < 20000), "Yes").otherwise("No"))
     ```
