PySpark Basic DataFrame Functions
----------------------------------------
read()
Reads data from a source into a DataFrame.
Example:
df = spark.read.csv("employees.csv", header=True, inferSchema=True)

show()
Displays the top rows of a DataFrame.
Example:
df.show()

printSchema()
Prints the schema of the DataFrame.
Example:
df.printSchema()

select()
Selects specific columns from the DataFrame.
Example:
df.select("name", "salary").show()

drop()
Drops a column from the DataFrame.
Example:
df = df.drop("age")

withColumn()
Adds or updates a column using a new expression.
Example:
from pyspark.sql.functions import col
df = df.withColumn("salary_int", col("salary").cast("int"))

withColumnRenamed()
Renames a column in the DataFrame.
Example:
df = df.withColumnRenamed("salary_int", "salary")

distinct()
Returns distinct rows of the DataFrame.
Example:
df.select("department").distinct().show()

describe()
Computes summary statistics of numeric columns.
Example:
df.describe("salary").show()


More PySpark DataFrame Functions
----------------------------------------
filter()
Filters rows using a condition.
Example:
df.filter(df.salary > 5000).show()

where()
Same as filter; filters rows using a condition.
Example:
df.where(df.department == "HR").show()

isin()
Checks if column values are in a given list.
Example:
df.filter(df.department.isin("HR", "IT")).show()

when()
Used for conditional logic (like CASE WHEN in SQL).
Example:
from pyspark.sql.functions import when
df = df.withColumn("status", when(df.salary > 5000, "High").otherwise("Low"))

alias()
Renames a column or expression temporarily.
Example:
from pyspark.sql.functions import col
df.select(col("salary").alias("monthly_salary")).show()
